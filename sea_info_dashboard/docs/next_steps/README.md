# Sea-Info Agent 다음 단계 개발 안내

작성일: 2026-10-26 · 대상: Python 기초와 FastAPI CRUD를 배우는 1인 개발자

## 이 문서의 목적

기획서와 현재 프로젝트를 연결해, 다음에 무엇을 만들고 어떤 기준으로 완료할지 정리한다. 해양생명과학 전공, 방사무늬 김의 내병성·고온내성 및 영양·기능성 성분 연구 경험은 **정보 검증과 해조류 콘텐츠 설계**에 활용한다. DB 백업 및 특허·기술문서·인증 업무 경험은 **복구 가능한 데이터 관리와 출처 추적**에 활용한다.

이 문서 묶음은 개발 계획이다. 새 API 연동, 키 발급, 배포 또는 앱 기능 변경을 완료했다는 뜻은 아니다.

## 먼저 할 일 세 가지

1. 실제 앱 파일인 `C:\KBR\sea_info_dashboard\main.py`와 `/docs`를 함께 보며 요청이 서비스 함수와 DB로 전달되는 흐름을 설명해 본다.
2. 국립해양조사원 조석·관측 API 활용신청을 각각 하고, 승인 후 로컬 `.env`에서 인증키를 설정한다.
3. 인천 한 지역·오늘 날짜로 실제 응답과 화면을 비교한다. 성공, 데이터 없음, 인증 실패를 구분해 기록한다.

사용자가 언급한 `.venv/Lib/site-packages/annotated_doc/main.py`는 외부 라이브러리 내부 파일이다. 앱 수정은 프로젝트 루트의 `main.py`에서 한다. `.venv`는 패키지가 설치된 실행 환경으로 취급한다.

## 계획을 읽는 기준

- **코드 있음:** 구현 파일에서 흐름을 확인했다는 뜻이다.
- **실제 검증 필요:** 실제 인증키·외부 응답·브라우저 동작을 별도로 확인해야 한다.
- **제안:** 앞으로 만들 기능·경로·테이블이며 현재 구현과 구분한다.

현재 상태는 로컬 코드와 기존 README를 기준으로 정리했다. 기존 README의 과거 테스트·실호출 결과는 과거 기록이며 이번 문서 작성에서 재실행한 결과가 아니다. 공식 데이터 제공 페이지는 작성일에 확인했지만 활용승인, 계정별 한도, 실제 데이터 수신은 별도 확인 대상이다. API 키와 개인 연구 원자료는 이 문서에 넣지 않는다.
