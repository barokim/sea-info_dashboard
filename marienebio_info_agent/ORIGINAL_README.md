# BARO.LOG — 바다와 AI 사이

김바로의 해양 × AI 개발 로그북. 한국어로 작성한 정적 사이트입니다.

## 구성

- `dist/index.html`: 메인 페이지, 프로젝트 소개, 학습 노트, 회고 폼
- `dist/styles.css`: 반응형 레이아웃과 시각 디자인
- `dist/app.js`: 프로젝트 필터, 모달, KPT/4L 회고 및 Markdown 내보내기
- `dist/favicon.svg`: 로고

별도 빌드나 런타임 패키지 없이 `dist`를 정적 파일로 제공합니다. 스크립트 문법은 `node --check dist/app.js`로 확인합니다. 서체는 Google Fonts를 사용하며, 불러오지 못하면 시스템 서체로 표시됩니다.

## 콘텐츠 기준

2026-10-26에 확인한 `barokim/guestbook`의 `main.py`와 `barokim/sea-info_dashboard`의 `README.md`를 바탕으로 작성했습니다. 실제 API 검증과 모의 응답 검증을 구분하며, 프로젝트 이미지와 다음 실험은 각각 UI 콘셉트와 제안으로 표시합니다. 학습 노트는 이 사이트를 위해 정리한 글이며 기존 블로그의 발행 글을 복제하지 않았습니다.

## 회고 데이터

회고 초안 하나를 브라우저 `localStorage`의 `baro-logbook-reflection-v1` 키에 저장합니다. KPT와 4L 입력값은 형식을 바꾸어도 보존합니다. 같은 초안의 날짜를 바꿔 쓸 수 있으며, 여러 주의 기록을 서버에 보관하는 기능은 없습니다. 서버 전송, 기기 간 동기화, 블로그 자동 발행을 수행하지 않습니다. 이전 주의 기록은 Markdown으로 내려받아 보관합니다.

## 확인한 동작

- JavaScript 문법 검사
- 프로젝트 분류 필터와 상세 모달
- 학습 노트 모달
- 회고 빈 내용 안내, KPT/4L 전환, 새로고침 후 초안 복원
- Markdown 내보내기 버튼의 생성·실행 흐름
- 데스크톱 및 375px 프레임의 메인·회고 레이아웃

테스트 브라우저에서는 내보내기 실행 안내까지 확인했으며, 다운로드 이벤트가 전달되지 않아 수신된 파일의 바이트 검증은 완료하지 못했습니다.
